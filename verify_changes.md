# Изменения в StringLib.cs и TableLib.cs

## Исправления в StringLib.cs

### 1. string.len(s)
- **Было**: Возвращало 0 для nil значения
- **Стало**: Вызывает ошибку "attempt to get length of nil value" (соответствует Lua 5.1 spec)

### 2. string.sub(s, i [, j])
- **Исправлено**: Условие `start > len + 1` вместо `start > len` для корректной обработки отрицательных индексов
- **Поведение**: Теперь правильно обрабатывает отрицательные индексы согласно спецификации Lua 5.1

### 3. string.lower(s)
- **Было**: Использовало .ToLower() для всех символов
- **Стало**: Преобразует только ASCII символы A-Z (a-z), как в оригинальном Lua

### 4. string.upper(s)
- **Было**: Использовало .ToUpper() для всех символов
- **Стало**: Преобразует только ASCII символы a-z (A-Z), как в оригинальном Lua

### 5. string.rep(s, n)
- **Исправлено**: Удалена поддержка sep параметра (не соответствует Lua 5.1 spec)
- **Добавлено**: Проверка на отрицательное число повторений

### 6. string.char(...)
- **Добавлено**: Проверка типа аргумента (должен быть number)
- **Добавлено**: Проверка на NaN и Infinity
- **Улучшено**: Сообщение об ошибке при выходе за диапазон 0-255

### 7. string.byte(s [, i [, j]])
- **Добавлено**: Проверка типа первого аргумента (string или number)
- **Исправлено**: Явное приведение к double для возврата значений

### 8. string.format(formatstring, ...)
- **Полная переработка**: Добавлена поддержка всех спецификаторов формата Lua:
  - %d, %i - целые числа
  - %f, %g, %e, %E - числа с плавающей точкой
  - %s - строки
  - %c - символы
  - %o - восьмеричные
  - %x, %X - шестнадцатеричные
  - %q - кавотированные строки
  - %% - процент
- **Добавлено**: Поддержка флагов (+, -, #, 0, пробел)
- **Добавлено**: Поддержка ширины поля и точности

### 9. PosRelAt()
- **Исправлено**: Логика для положительных значений (теперь просто cast to int)

## Исправления в TableLib.cs

### table.sort(table [, comp])
- **Улучшено**: Обработка компаратора - теперь возвращает 0 для равных элементов
- **Улучшено**: Сравнение строк отдельно от других типов
- **Добавлено**: Явная обработка разных типов через строковое представление

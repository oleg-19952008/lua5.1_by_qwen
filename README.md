# lua5.1_by_qwen

Луа 5.1 на C# для .NET 4.8

## Официальные спецификации и стандарты Lua 5.1.4

Этот проект реализует язык программирования Lua версии 5.1.4, основываясь на официальных спецификациях и стандартах.

### Основные документы

1. **Lua 5.1 Reference Manual** (Официальное руководство по ссылке)
   - Полный справочник по языку Lua 5.1
   - URL: https://www.lua.org/manual/5.1/manual.html
   - Содержит полное описание синтаксиса, семантики и встроенных библиотек

2. **Lua 5.1 Source Code** (Исходный код)
   - Эталонная реализация от создателей языка
   - URL: https://www.lua.org/source/5.1/
   - Версия 5.1.4 является стабильной релизной версией

3. **The Lua Programming Language** (Книга)
   - Авторы: Roberto Ierusalimschy, Luiz Henrique de Figueiredo, Waldemar Celes
   - Издательство: Addison-Wesley
   - ISBN: 978-8590379836

### Ключевые особенности Lua 5.1.4

- **Типы данных**: nil, boolean, number, string, function, userdata, thread, table
- **Лексическая область видимости** с замыканиями
- **Динамическая типизация**
- **Автоматическое управление памятью** (garbage collection)
- **Таблицы** как универсальная структура данных
- **Корутины** (cooperative multitasking)
- **Мета таблицы** и мета методы для расширения возможностей

### Синтаксические стандарты

- Комментарии: `--` для однострочных, `--[[ ... ]]` для многострочных
- Блоки кода определяются ключевыми словами (do/end, if/then/end, function/end и т.д.)
- Операторы: +, -, *, /, %, ^, #, ==, ~=, <=, >=, <, >, and, or, not
- Управляющие конструкции: if, while, repeat, for, function, break, return

### Встроенные библиотеки

- **Базовые функции**: print, type, tonumber, tostring, loadstring и др.
- **Модуль string**: манипуляции со строками
- **Модуль table**: операции с таблицами
- **Модуль math**: математические функции
- **Модуль io**: ввод-вывод
- **Модуль os**: взаимодействие с операционной системой
- **Модуль debug**: отладочные функции
- **Модуль coroutine**: работа с корутинами

### Лицензия

Lua распространяется под лицензией MIT, что делает его свободным для использования в любых целях.

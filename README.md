# Lua 5.1.4 Port to C# (.NET Framework 4.8)

Порт языка программирования Lua версии 5.1.4 на C# для платформы .NET Framework 4.8.

## Описание проекта

Этот проект представляет собой реализацию интерпретатора Lua 5.1.4 на языке C#, предназначенную для использования в средах .NET Framework 4.8. Порт сохраняет полную совместимость с оригинальной спецификацией Lua 5.1.4 и позволяет выполнять Lua-скрипты непосредственно внутри .NET-приложений.

## Цели портирования

- Обеспечить возможность выполнения Lua-скриптов в приложениях .NET Framework 4.8
- Сохранить полную совместимость с оригинальной спецификацией Lua 5.1.4
- Предоставить удобный API для интеграции Lua с C#-кодом
- Обеспечить производительность, сопоставимую с нативной реализацией

## Ключевые особенности реализации

### Типы данных Lua в C#

Реализованы все стандартные типы данных Lua 5.1.4:
- `nil` → `null` в C#
- `boolean` → `System.Boolean`
- `number` → `System.Double` (согласно спецификации Lua 5.1)
- `string` → `System.String`
- `function` → делегаты и лямбда-выражения C#
- `userdata` → пользовательские объекты .NET
- `thread` → корутины на основе `IEnumerator`
- `table` → специализированная структура данных с гибридным массивом/хэш-таблицей

### Архитектурные решения

- **Виртуальная машина Lua**: реализация стековой VM, аналогичной оригинальной
- **Сборщик мусора**: портированный алгоритм generational garbage collection
- **Мета таблицы**: полная поддержка мета методов
- **Корутины**: реализация cooperative multitasking через yield/return
- **Closures**: поддержка лексической области видимости и замыканий

### Синтаксические стандарты

Полная поддержка синтаксиса Lua 5.1.4:
- Комментарии: `--` для однострочных, `--[[ ... ]]` для многострочных
- Блоки кода определяются ключевыми словами (do/end, if/then/end, function/end и т.д.)
- Операторы: +, -, *, /, %, ^, #, ==, ~=, <=, >=, <, >, and, or, not
- Управляющие конструкции: if, while, repeat, for, function, break, return

## Встроенные библиотеки

Реализованы все стандартные библиотеки Lua 5.1.4:

- **Базовые функции**: print, type, tonumber, tostring, loadstring, getfenv, setfenv и др.
- **Модуль string**: манипуляции со строками, включая pattern matching
- **Модуль table**: операции с таблицами (insert, remove, sort, concat и др.)
- **Модуль math**: математические функции (sin, cos, tan, exp, log и др.)
- **Модуль io**: ввод-вывод (адаптирован для .NET Stream API)
- **Модуль os**: взаимодействие с операционной системой (через .NET Framework APIs)
- **Модуль debug**: отладочные функции
- **Модуль coroutine**: работа с корутинами
- **Модуль package**: система загрузки модулей

## Интеграция с .NET Framework 4.8

### Требования к среде

- .NET Framework 4.8
- C# 7.3 или выше (совместимый с .NET Framework 4.8)
- Поддержка CLR 4.0

### Особенности интеграции

- **Interop с C#**: возможность вызова C# методов из Lua и наоборот
- **Reflection**: использование .NET Reflection для работы с объектами
- **Exception Handling**: корректная обработка исключений между Lua и .NET
- **Thread Safety**: поддержка многопоточного выполнения скриптов

## Пример использования

```csharp
using LuaInterface;

// Создание состояния Lua
var lua = new LuaState();

// Выполнение Lua-кода
lua.DoString(@"
    function add(a, b)
        return a + b
    end
    
    result = add(10, 20)
    print('Result: ' .. result)
");

// Получение результата из C#
var result = lua.GetGlobal("result");
Console.WriteLine($"C# received: {result}");

// Очистка ресурсов
lua.Dispose();
```
